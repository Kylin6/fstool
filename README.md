## 🌟 三重八字录入模式

系统支持三大输入方式，满足各种使用习惯：
1. **🌞 公历 (阳历) 生日**：标准公历日期选择器（年月日时），自动转换农历与排出生辰四柱。
2. **🌙 农历 (阴历) 生日**：专门为只记得阴历生日的长辈与新人打造，支持自由选择农历年份（1930-2035）、月份（正月~腊月）、**智能识别当年闰月并支持勾选**、农历日期（初一~三十）与出生时辰，下方自动显示换算出的对应公历日期！
3. **📜 自选八字干支**：若已找命理先生排好命盘，支持直接下拉选取年柱、月柱、日柱、时柱天干地支，方便专业人士。
